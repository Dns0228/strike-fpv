# STRIKE FPV 2.0

Ударный FPV-симулятор от первого лица. Полигон «Дельта»: разные цели, разный урон, три боевые части и камикадзе.

## Играть

- **WASD** — тяга и рысканье
- **Мышь** — куда смотрит дрон
- **Стрелки** — тангаж и крен
- **ЛКМ / Shift** — огонь
- **1 / 2 / 3** — осколочная / ОФ / бронебойная
- **X** — подрыв
- **P** — пауза

На телефоне: левый стик — тяга, правый — тангаж и крен.

## Стек

React 19, TanStack Start, Three.js, Vite, Tailwind. Сборка заточена под Vercel (Nitro preset).

```bash
npm install
npm run dev
```
