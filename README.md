# STRIKE FPV 2.0

Играть: **[strike-fpv.vercel.app](https://strike-fpv.vercel.app)**

Ударный FPV-симулятор от первого лица. Полигон «Дельта»: свободный полёт, оборона линии и штурм.

## Режимы

- **Свободный полёт** — полигон без задачи, три БЧ, ветер, скан, автоприцел, тепловизор. ЗРК и БМП отвечают огнём, колонны едут по грунтовке, посадка на площадке заряжает
- **Аркада** — FPV на линии, три волны (на третьей грузовик), не дать прорвать ленту
- **Штурм** — солдат или пикап от третьего лица, дойти до ленты, прячась от охотничьих FPV с лучами; в рощах захват сбрасывается быстрее

В ангаре: инверсия Y, звук, тряска, **день / ночь**, **автоприцел**, **оптика**.

## Управление

FPV:

- **W** — вперёд (нос чуть вниз)
- **S** — назад / снижение
- **A / D** — рысканье
- **Пробел** — набор высоты
- **Мышь** — куда смотрит дрон
- **ЛКМ / Shift** — огонь
- **1 / 2 / 3** — осколочная / ОФ / бронебойная
- **X** — подрыв
- **T** — скан сектора
- **N** — тепловизор / ПНВ
- **P** — пауза

Штурм:

- **W / S** — ход
- **A / D** — поворот
- **Мышь** — камера вокруг
- **Пробел** — бег / газ
- **Ctrl** — присесть (солдат)
- **T** — слух (пеленг охотника)
- **N** — тепловизор / ПНВ

На телефоне: горизонтально. Левый стик — ход, правый — камера / крен. Справа: огонь, скан / слух, ТПВ.

Геймпад: левый стик — полёт / ход (влево = влево), правый — взгляд. RT / A — огонь (FPV) или газ (штурм). Y — скан. Select / RS — оптика.

Рекорд хранится на этом устройстве.

## Стек

React 19, TanStack Start, Three.js, Vite, Tailwind. Сборка заточена под Vercel (Nitro preset).
